WHEESE ESTUDOS - PUBLICAÇÃO NA INTERNET

1. Crie um repositório no GitHub e envie TODOS estes arquivos mantendo a pasta assets.
2. No Render, crie um Web Service ligado ao repositório.
3. Build Command: npm install
4. Start Command: npm start
5. Adicione a variável de ambiente:
   GEMINI_API_KEY = SUA_CHAVE_GEMINI
6. O Render fornece HTTPS automaticamente e um endereço *.onrender.com.
7. Para domínio próprio, adicione o domínio em Settings > Custom Domains e configure o DNS indicado pelo Render.

NUNCA coloque a chave Gemini no index.html, no GitHub ou no código público.
